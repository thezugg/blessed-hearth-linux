# Blessed Hearth for Linux

An unofficial, community-maintained Linux port of [Blessed Hearth](https://github.com/ShardStack/blessed-hearth).

## Original Project

**Blessed Hearth was created and developed by ShardStack.**

All credit for the original application, interface, addon management engine and functionality belongs to the original developer.

This repository contains Linux compatibility modifications intended to make Blessed Hearth run natively on Linux distributions such as CachyOS, Arch Linux and others.

## About This Port

This project started as a personal effort to run Blessed Hearth on Linux without Wine.

It is not intended to replace, compete with or take credit for the original project.

The aim is simply to make the application usable on Linux and share the modifications with anyone who might find them helpful.

The Linux port is experimental, unofficial and is not affiliated with or endorsed by ShardStack.
